# 侧边栏面板与活文件安全约定

> **这份文件什么时候读**：要在面板上操作（换关卡 / 选活文件 / 一键还原），或要弄清「它到底会写哪些文件」时。
> 它是插件主文档 [`README.md`](../README.md) 的参考文件 —— README 只留入口、速查与导航。
> ⚠️ 一句话：**活文件是唯一副本**（没有 git、没有撤销）—— 这里的规矩是「宁可失败，也不许损坏」。

## 侧边栏面板

注册在官方槽位 `sidebar.footer.action`（侧栏底部「设置」旁），点开是一个状态浮层。
**粉蓝主调**（浅蓝 `#7dd3fc` ↔ 粉红 `#f9a8d4`），入口图标是内联的像素画 PNG
（`lib/assets/icon.png`，内联进 bundle，换图不用改路由、也不依赖宿主静态服务）。

布局是**卡片网格**（参考蛋仔面板的 `.eggy-body` / `.eggy-col`）：头部固定、每栏各自独立滚动。
每页的栏数**不一样**：初级功能 = **两栏**（① 当前关卡/地图体检 ｜ ② 存盘与进程），
高级功能 = 一栏（③ 日志与画面），其余页 = 「左设置 ｜ 右试玩画面」两栏。
（历史上是三栏「关卡 / 代码 / 日志」—— 2026-10-01 按作者要求重排过，见 §「初级功能页」那两行表。）

浮层里是**七个页面**（顶部页面条，`panelTab`）；**只改 `lib/client.js` 就刷新页面（F5）即可**，只有 Host 半边才要重启 `dsh web`：

### 「整体存盘状态」怎么算的（2026-10-01 作者要求）

一次 `miliastra_health { op:'sha', all:true }` 拿**全部活文件**的三方表，然后按**关卡**给一句话结论
（纯函数 `saveVerdict`，在 `lib/client.js` 里，单独回归）：

| 情形 | 结论 | 下一步 |
|---|---|---|
| `liveSha === embeddedSha`（全部） | ✅ **已存盘：N / N 个脚本与地图里嵌的一致** | 可以直接（停掉再）试玩 |
| 有不等的 | ⚠️ **有 M / N 个脚本没存盘** + **点名** | 去编辑器里**存一次盘**（游戏跑的是存盘那一刻嵌进 `.gil` 的那份） |
| `mounted === false`（没挂进地图） | **单列**，不算进"没存盘" | 这些改了也不会生效 |
| 缺 sha（比不出来） | ❔ **说不清** | **不替它说"已存盘"**（宁可说不知道） |
| 一个活文件都没有 | 还没有活文件 | 先在编辑器里给容器节点挂客户端脚本 |

> ⚠️ 与逐文件的「脚本一致性」是**两件事**：那张卡比的是"地图快照 vs 本地活文件"（选中的那一个），
> 这张卡比的是"**全部**活文件 vs 地图里嵌的那份" —— 前者在右栏折叠的代码操作里，后者才是作者要的"整体有没有保存"。
> ⚠️ 口径只说这两列能推出来的事：`.gil` 是**存盘那一刻的快照**，不是实时的。（AI 侧的 `op=sha` 在**没给 `mirror`** 时
> 会把这类行记成 `unknown`、`summary.consistent` 为 0 —— 面板不依赖那个 `summary`，自己按 `liveSha`/`embeddedSha` 判，见回归。）

### 关卡切换与「自动跟随」

> ⚠️ **2026-10-01 起：面板上没有关卡选择器了**（作者：「关卡 做个块可以删除了」「我只关心打开的是哪个关卡」）——
> 初级页只留**一行**「当前关卡」，所以面板**永远自动跟随**：`activeLevel` 恒为空，所有调用都让 Host 自己判定当前关卡。
> **工具侧不受影响**：AI 调 `miliastra_code op=deploy` 时**仍然必须显式带 `level`**（那是防"投错图把别人的活文件覆盖掉"的那条纪律）。
> （更早的面板有「点某一关即手动锁定 / 再点回到自动跟随」那套；0.6.3 及以前有效，现在**不存在了**。）

「当前关卡」怎么判：`miliastra_health` 每次都会重新判定「当前正在开发的关卡」（有活文件 + 最近改动），
作者在编辑器里换图，面板下一轮就跟着切过去 —— **不用手点**。

> 本机实测 `Beyond_Local_Save_Level` 下有 **18 个关卡**（8 个是直接躺在根目录的 `.gil`，
> 那部分是"不在这台机器上编辑的图"）。**两种布局都扫**，只扫一种会漏掉大部分。

### 一个关卡可以有多个活文件

不同角色 / 不同模块可以各挂一个客户端脚本，`external_lua_file\` 下就会有多个 `.lua`。
所以「当前操作哪一个」是**显式**的：

- 面板：列② 顶部的**活文件选择器**，点一下切换；切了之后体检/比对/备份/部署/还原全部跟着切
- 工具：所有相关 op 都收 `file` 参数
  - 省略 → 先按名字关键词（`双相`/`测试`/`main`/`levelScript`），再退到**最近改动**的那个
  - 给了名字但不存在 → **明确报错并列出全部**，绝不悄悄换成别的文件
- 备份是**按文件隔离**的（`_backup\` 里按文件名前缀分组）

### 面板里读「任意本地 .lua」（绝对路径）—— 只读

上面那套是**沙箱活文件**（`external_lua_file\` 里正在开发的那张图，路径随账号/换图而变）。
**手上任何一份 `.lua`**（桌面上的草稿、同事发来的脚本……）走的是另一条入口：
**模拟器页 → 左列最上面那张独立小卡「读本地 .lua（绝对路径）」**
（2026-09-25 从「④ 工程与控件树 / 工程适配」里提上来的 —— 作者原话「绝对路径的入口放做在左边最顶上」）。

| 你做什么 | 它做什么 | 会不会写盘 |
|---|---|---|
| 粘上绝对路径 → 点**「读取」** | `miliastra_code op=read`（元信息 + 正文预览）+ `miliastra_sim op=handover`（候选交接值） | **只读**：不备份、不改文件、不建目录 |
| 点**「用它搭进模拟器」** | `miliastra_sim op=bind`：把这份脚本投进**模拟器工程**并起一次会话 | 只动模拟器工作区；**沙箱活文件与地图存档都不碰** |

「读取」给三样东西（作者的原话是「先给我看」）：

1. **一行元信息**：字节 / 行数 / `sha256` 前 12 位 / 修改时间 / 有没有 BOM；
2. **正文预览**：等宽字体、可滚动，前 60 行（超了会注明总行数）；
3. **候选交接值**：`变量名 = 值`（+ 猜的 kind）与它建议的模板 / 容器索引 ——
   勾选与 kind 就在下面那张「候选交接值」表里改（**读取会替换它**），确认无误再点「用它搭进模拟器」。

只读这条路径的边界（工具侧 `miliastra_code op=read source=…` 是同一套）：

- **必须是绝对路径**（`C:\…` 与 `C:/…` 都认）：面板与工具的运行目录不可预期
  （插件目录 / 会话工作区 / 编辑器当前目录都可能），相对路径会指向**别的文件**，所以**直接拒绝**；
- 文件不存在 / 是目录 / 是二进制（含 NUL 字节）/ 不是合法 UTF-8 / **超过 8 MB**
  → 一律**明确拒绝并给出下一步**，绝不把乱码回给你；
- **只读就是只读**：这条路径不写任何文件，也**不给写操作开口子** ——
  `deploy` / `restore` / `fixbom` 的 `source` / `backup` 语义**一字未动**（活文件的安全约定全部照旧）。

> 「搭进模拟器」的语义：它把这份 `.lua` 当**真机工程脚本**挂进模拟器（模板索引用你交接的值、
> 容器索引用你填的那个），然后起一次会话回答「脚本跑没跑、控件建了几个」。
> 它**不是部署**：不写 `external_lua_file\`，不碰 `.gil`，也不影响正在试玩的那一局。

### 备份与还原（活文件是唯一副本，所以这里全是硬规定）

活文件没有 git、没有撤销，**覆盖即丢失** —— 所以下面这套「备份 + 校验 + 失败自动还原」就是唯一的安全网。

| | 说明 |
|---|---|
| **备份什么** | **只有活文件 `.lua`**（不备份 `.gil`、不备份已发布的图） |
| **什么时候** | `op=deploy` 覆盖前自动备份；`op=backup` 手动；`op=restore` 还原前**再备份一次当前版本** |
| **备份到哪** | **就在被替换文件的旁边**：活文件同级 `_backup\`。`MILIASTRA_BACKUP_DIR` 只为测试隔离，一般不要动 |
| **备份叫什么** | 每次写**两份**：固定名 **`<原名>.bak`**（= 最近一次覆盖前的那一版）+ 历史 `<原名>.<本地时间戳>_备份.lua` |
| **为什么要有固定名** | 还原时**不用挑版本**：`op=restore` 不传 `backup` 就用 `.bak`。挑时间戳是错误来源之一 |
| **会互相覆盖吗** | 历史那份不会：**同秒撞名自动顺延 `-2 / -3`**。`.bak` 按定义会被下一次覆盖更新 |
| **备份失败怎么办** | **中止覆盖，活文件零改动** —— 绝不带着「没有备份」去写。（以前是「记一笔错误然后照样覆盖」，已修） |
| **断电会不会写坏** | 不会。**原子写**：同目录临时文件 → `fsync` → `rename` 替换。目标要么还是旧内容，要么已是完整新内容 |
| **写完怎么确认** | 比对 SHA-256。比对不上 ⇒ **自动还原到覆盖前那一版** —— 这是写盘的**安全网**，不是危险动作：那笔写入没生效，但版本一点没丢（部署与还原都如此）。回执 `rolledBack:true` 说的就是这件事 |
| **还原安全吗** | ① 先列出让你选（或用固定名一键）② **还原前把当前版本再备份一份** ③ 原子写 ④ 比对 SHA，比不上就**自动还原到你刚要还原前的那版**（= 什么都没发生）⑤ 回报「从哪份还原 / 当前 sha / 安全备份路径 / 下一步」 |
| **拒收什么** | 带 UTF-8 BOM 或非法 UTF-8 的备份 —— **还原坏文件比不还原更糟** |
| **能跳过备份吗** | `noBackup:true` 必须**同时**传 `allowNoBackup:true`（双钥匙）；正常部署不要用 |
| **会删旧备份吗** | **不会**。份数 ≥20 或总占用 >5 MB 时只提示，清理由你自己决定 |

```powershell
miliastra_code op=backups                  # 列备份（含固定名路径与 ★ 标记）
miliastra_code op=backup                   # 手动备份（写固定名 + 历史各一份）
miliastra_code op=restore                  # 还原到固定名那份（最省事，不用挑版本）
miliastra_code op=restore backup=<路径>     # 还原到指定某一版
miliastra_code op=inspect file=角色B.lua    # 指定活文件体检（含 SHA-256）
```

**面板上更快**：右栏「备份」卡片里有 **「还原到最新备份」** 一键按钮，以及 `★` 标出的固定名那份。
